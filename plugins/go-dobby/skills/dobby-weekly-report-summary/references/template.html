펀딩 상세에서 메이커를 팔로우해도 소식받기가 켜지지 않던 문제

소식받기는 메이커가 새 프로젝트를 열 때 알림을 받는 설정입니다. 예전 국내 화면은 팔로우할 때 이 설정도 함께 켜 줬습니다. 7월 2일 국내 상세가 해외용 화면과 하나로 합쳐지면서 이 단계가 빠졌습니다.

이전 (7/2 이후)팔로우만 되고 소식받기는 꺼진 채였습니다. 마케팅 수신에 동의한 사람도 메이커의 새 프로젝트 알림을 받지 못했습니다.
지금국내에서 팔로우하면 마케팅 동의자는 소식받기가 켜지고 앱 알림 설정 안내가 뜹니다. 언팔로우하면 소식받기도 꺼집니다. 해외 화면은 예전 그대로입니다.

국내에서 팔로우 버튼을 누르면

  1. 로그인하지 않았으면 로그인 화면으로 보냅니다.
  2. 휴대폰 번호가 없으면 휴대폰 인증 창을 먼저 띄웁니다. 인증하면 소식받기와 마케팅 동의를 켭니다.
  3. 팔로우 요청을 보냅니다. 성공 응답(SUSS000)일 때만 다음으로 갑니다.
  4. 버튼을 누른 시점에 마케팅 동의 여부를 확인합니다. 동의자면 소식받기를 켭니다.
  • 고친 곳: 공용 팔로우 처리에 국내 전용 순서를 되살렸습니다. 펀딩 상세 메이커 프로필과 스토어 상세 메이커 정보의 팔로우 버튼이 이 처리를 씁니다.
  • 함께 고쳐진 곳: 알림신청이나 찜 뒤에 뜨는 팔로우 창은 원래 공용 처리를 써서 코드 변경 없이 같이 고쳐졌습니다.
  • 핫픽스 리뷰에서 보강한 것: 버튼 연타 막기(처리 중 로딩 표시), 로그인이 풀리면(401 응답) 로그인 화면으로 보내기, 소식받기만 실패하면 팔로우 결과 안내 띄우기, 팔로잉 목록과 개수를 바로 바꾸기.
  • 서버: 바꾼 것이 없습니다. 이미 있던 팔로우 요청과 소식받기 요청을 그대로 씁니다.
