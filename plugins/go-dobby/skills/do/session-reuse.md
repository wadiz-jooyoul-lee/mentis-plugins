# 세션 이어 쓰기 판정 (근거)

`/do` 는 단계마다 새 세션이 기본이다. 이 문서는 언제 직전 세션을 이어 쓰는 쪽이 싼지와 그 근거를 적는다. 판정은 `reference/dobby-lib.sh` 의 `dobby_v2_reuse_ok` 한 곳에서 한다. 이 판정을 쓰는 곳은 둘이다.

| 쓰는 곳 | 하는 일 |
|---|---|
| `run.sh`(자동 실행) | 이어 쓰는 쪽이 싸면 `claude -p --resume {직전 세션}` 으로 다음 세션을 띄운다 |
| 대화형 세션 마무리(`dobby_v2_next_hint`) | 이어 쓰는 쪽이 쌀 때만 `다음` 칸에 "/clear 없이 이어서" 안내를 낸다. 아니면 아무것도 출력하지 않는다 |

이 문서는 SKILL.md 에 넣지 않는다. 스킬 본문은 세션마다 문맥에 실려 호출마다 다시 읽힌다. 근거 설명까지 넣으면 그 비용이 판정으로 아끼는 양보다 커진다.

## 조건과 근거

기본은 단계마다 새 세션이다. 아래를 **모두** 만족할 때만 `run.sh` 가 직전 세션을 `claude -p --resume {직전 세션}` 으로 이어 쓴다. 이어 써도 세션 아이디는 그대로다.

| 조건 | 기준 | 왜 |
|---|---|---|
| 이번에 할 일이 수정이다 | 단계 판정 표의 "수정" 두 줄과 같은 조건(리뷰 지적이 남음, 또는 검증 실패) | 수정은 직전 리뷰·검증 세션이 본 것을 그대로 이어받는다. 리뷰는 독립성이 필요해 이어 쓰지 않는다 |
| 직전 세션의 마지막 문맥이 작다 | 120,000 토큰 이하 | 이어 쓰면 호출마다 그 문맥 전체를 다시 읽는다 |
| 직전 호출 뒤 오래 지나지 않았다 | 300초(5분) 이하 | 캐시가 만료되면 누적 문맥 전체를 비싼 값으로 다시 캐시에 쓴다 |

근거는 FE1-2139~FE1-2142 의 세션 기록 34개를 잰 값이다. 비용은 캐시 안 쓴 입력 1 기준으로, 캐시 쓰기 5분 1.25배, 1시간 2배, 캐시 읽기 0.1배로 환산했다.

- 새 세션의 시작 문맥은 5.7만~9.2만 토큰이고, 첫 호출 비용은 4.3만~10만이다.
- 이어 쓰면 호출마다 0.1 × (직전 문맥 − 새 시작 문맥)을 더 낸다. 수정 세션은 15~21번 호출하므로, 직전 문맥이 12만을 넘으면 새 세션보다 비싸다.
- 실제 사례: 문맥 17.7만인 검증 세션을 이어 쓴 수정(`31d5011c`)은 17번 호출에 36.9만이 들었다. 새 세션으로 연 수정(`239e1ba6`)은 16번 호출에 28.4만이었다.
- 캐시 유지 시간은 대화형 세션에서 5분, 헤드리스 세션에서 1시간이 관측됐다. 확인될 때까지 짧은 쪽에 맞춘다.

검증 세션은 끝날 때 문맥이 10만~23만이라, 검증 실패 뒤의 수정은 대부분 새 세션이 된다. 이 판정은 크게 아끼는 장치가 아니다. 이어 쓰다가 손해 보는 경우를 막는 장치다.

## 대화형 안내의 비용

| 항목 | 값 | 근거 |
|---|---|---|
| 판정 계산 | 모델 토큰 0 | 셸(jq)이 세션 기록 파일을 읽어 계산한다. 마무리 때 이미 부르는 명령에 붙여 도구 호출이 늘지 않는다 |
| 평소(이득 아님) | 0 | 아무것도 출력하지 않는다 |
| 이득일 때 | 약 1,000 | 안내 세 줄(도구 출력 약 220토큰을 캐시에 씀)과 마지막 응답에 옮겨 적는 출력 약 150토큰(출력은 입력의 5배로 셈) |
| SKILL.md 에 더한 지시 | 약 2줄 | 세션마다 실린다. 그래서 짧게 둔다 |
| 이득일 때 아끼는 양 | 약 3.7만(추정) | FE1-2139 검증 세션 `e0cca658`(끝 문맥 102,446) 다음의 검증 실패 수정. 실제 새 세션 비용 28.4만에서 첫 호출 7.4만을 아끼고, 호출마다 더 읽는 약 2.6만을 더 낸다 |

네 오더(FE1-2139~FE1-2142)의 세션 전환 약 30번 중 이어 쓰기가 이득이었던 경우는 1번이다. 그래서 매번 출력하면 판정 비용(30번 × 약 1,000)이 아끼는 양(약 3.7만)과 비슷해진다. 이득일 때만 출력하는 이유다.

대화형은 사람이 언제 다음 명령을 칠지 모른다. 캐시(5분)가 지난 뒤 이어 쓰면 누적 문맥 전체를 다시 캐시에 써서 새 세션보다 비싸다. 그래서 안내에 기한(지금+4분)을 적는다.
