# 세션 6-3 · 판단 답 받기 (기획자)

보류된 오더에서 사람과 대화하는 세션이다. `design.md` 의 `## 확인이 필요했던 것` 마지막 항목을 보여 주고 답을 받는다. 자동 배포 오더든 사람이 돌리는 오더든 같다.

`/do {키} 답 "{내용}"` 으로 시작한 세션은 묻지 않고 그 내용을 답으로 쓴다. 답이 코드를 고치라는 것이면 그 답이 곧 변경 확정이다. 변경 절을 쓴 뒤 따로 묻지 않고 `dobby_design_ack {키} 사용자` 로 확정을 기록한다.

1. 답을 `## 결정과 근거` 에 적는다.
2. 답에 따라 고치고 끝낸다.

| 답 | 하는 일 | 끝내는 줄 |
|---|---|---|
| 코드를 고친다 | `steps/change.md` 대로 변경 절을 쓰고 확정받는다(`dobby_design_ack {키} 사용자`) | `dobby_v2_end {키} 변경접수` |
| 배포를 다시 한다 | 막힘 비고가 남은 행은 사람이 풀었다는 답을 받은 뒤 `dobby_ship_stage` 로 비고 없이 다시 적는다 | `dobby_v2_end {키} 재배포` |
| 검증을 다시 한다 | 테스트 계획을 고치기로 했으면 고치고 `steps/design.md` 의 1-5 자족성 점검을 다시 돈다 | `dobby_v2_end {키} 재검증` |
| 아직 못 정했다 | `## 확인이 필요했던 것` 에 새로 나온 질문을 적는다 | `dobby_v2_end {키} 판단요청 "{질문 한 줄}"` |

3. 자동 배포 오더면 끝낸 뒤 `dobby_v2_autorun {키}` 로 자동 실행을 다시 띄운다. `자동 배포 환경` 줄은 그대로라 배포와 검증까지 다시 간다.
