# 세션 5-2 · 배포 (자동 배포 오더 · 배포담당)

진행은 상태 문서 `## 배포` 표가 나타낸다.

1. `dobby-ship` 스킬 절차를 `{키} {자동 배포 환경}` 으로 따른다. 그 스킬의 **"자동 실행에서"** 절대로 한다 — 머지·빌드·sync 를 묻지 않고, 리뷰봇과 빌드를 기다리지 않고, 검증은 하지 않는다.
2. 아래 자리에 닿으면 끝 헬퍼로 끝낸다. 다음 세션은 자동 실행이 정한다.

| 닿은 자리 | 끝내는 줄 |
|---|---|
| `리뷰 대기`·`빌드 대기`·`배포 대기` | `dobby_v2_end {키} 기다림` |
| 모든 저장소가 `배포 확인` | `dobby_v2_end {키} 배포확인` |
| 막혀서 못 나아감 | 그 행의 비고에 무엇이 왜 막혔는지 적고(`dobby_ship_stage` 의 비고 칸) `dobby_v2_end {키} 막힘` |
| 사람의 승인이 꼭 필요함 | `dobby_v2_end {키} 사람승인 "{무엇을 승인받아야 하는지}"` |

끝 헬퍼는 고른 결과가 배포 표와 맞는지 확인한다. 맞지 않으면 `거부:` 를 낸다.
